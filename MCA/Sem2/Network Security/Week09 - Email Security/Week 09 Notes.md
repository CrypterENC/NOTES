## Introduction to PGP - Pretty Good Privacy.
- **PGP** is used as E-mail encryption scheme
- **Uses MD5 or SHA** for calculating message digest.
- **RSA** for public key encryption.
## Working of PGP
- Installed PGP software
- Create a public key pair for user.
- Gives user option to **digitally sign the message** (**integrity**) or **encrypt message** (**confidentiality**) or both.
- **Message appears** after **MIME header.**
## Public Key Pair
- **Private Key**
	- Protected by password
	- Each time key is accessed, password is needed.
- **Public Key**
	- Available in user's website or public server.
## Public Key Certificate
- PGP public key is certified by Web of Trust
